规划助手

面向规划设计场景的多 Agent 智能体平台

统一对话入口，按意图分流到规范问答或方案审核，并支持系统初审与人工终审闭环。

查看源码 架构说明

双产品

三档模式：自动 / 规范智库 / 规划通，由 Orchestrator 路由到对应子图。

规划通

PDF 结构化抽取 → 五维并行评分 → 加权总分与问题清单 → 可选人工认领、改分与终审。

规范智库

意图分类 → 直答或 RAG 检索生成 → SSE 流式输出 → 正文引用高亮与正式规范标号。

技术栈

异步 Python 服务端 + 静态前端；Agent 编排与可溯源检索分离部署。

  • Python 3.11
  • FastAPI · SSE
  • LangChain · LangGraph
  • RAG · Milvus
  • PostgreSQL
  • DeepSeek-V3
